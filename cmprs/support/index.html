How do I install CMPRS on Mac?

Download the DMG, open Install CMPRS, and click Install. The app goes into ~/Applications and one Finder service is registered. Requires Apple Silicon and macOS 13 or later.

Where is the Finder action?

Select video files and open the context menu. Look for CMPRS — Compress video; macOS may place it under Services. If hidden, enable it in System Settings → Keyboard → Keyboard Shortcuts → Services → Files and Folders.

Where are the results?

A separate CMPRS-[name].mov appears beside the original only if smaller. Existing files are never overwritten. macOS may ask you to allow that exact source folder.

How is the language selected?

The app follows the system/application language: Russian or English, with English as the fallback. Relaunch after changing the language in macOS or Windows. The website has its own EN/RU switch and opens in English for new visitors.

Why was a file skipped?

A result is discarded if it is not smaller. Unsupported HDR/Dolby Vision, transparency, pixel formats or tracks are left unchanged. Compatible H.264 uses 8-bit 4:2:0; reducing 10/12-bit depth requires confirmation for the batch.

What if processing stops?

Use Cancel. CMPRS stops the encoder and removes its temporary output. The queue shows a short error for files that fail. Email the app and operating system versions, computer model, input format and visible error to uralsocket@gmail.com. CMPRS does not save log files or diagnostic reports.

How do I remove the Finder action?

Disable CMPRS — Compress video under Keyboard → Keyboard Shortcuts → Services → Files and Folders. Old Automator workflows can be removed from ~/Library/Services. Removing the app does not delete your videos.

How do I install CMPRS on Windows?

Choose Windows on the homepage, open the setup EXE and click Install. The installer includes FFmpeg and adds CMPRS to the Start menu, File Explorer and Installed apps for your account. Requires Windows 10 22H2 or Windows 11, Intel/AMD x64 and .NET Framework 4.8. Microsoft WebView2 installs automatically if missing; that step requires internet. The Windows build is unsigned, so Windows may show a publisher warning.

Where is the Windows action?

Select videos in File Explorer, right-click and choose CMPRS — Compress video. On Windows 11, open Show more options (Shift+F10). Send to → CMPRS also works for a batch. All selected videos share one queue.

How do I update or remove the Windows app?

Close CMPRS and run the new installer to update. To remove the application and its Explorer action, use Settings → Apps → Installed apps → CMPRS → Uninstall. Your video files are not removed.
