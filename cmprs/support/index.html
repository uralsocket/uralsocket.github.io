Quick answers.

Which mode should I choose?

H.264 creates 8-bit video for broad playback support on Mac, iPhone and Windows. HEVC aims for more efficient compression and preserves supported 10-bit. Windows may need an HEVC extension or a compatible player. Both output MOV with 4:2:0 color sampling. Converting a 10-bit source to 8-bit H.264 requires your explicit permission in the app.

Where are the Finder actions?

The website installer installs CMPRS and both Automator Quick Actions together: CMPRS — H.264 and CMPRS — HEVC. Select videos in Finder, right-click, then open Quick Actions. If macOS has disabled them, enable them in Finder Extensions settings. These instructions describe the website edition. An App Store edition has not been released.

Why does CMPRS ask for a folder?

On first use, allow the indicated source folder in the macOS picker so CMPRS can save next to the originals. Only that folder is remembered. The app also needs enough free space for a temporary result.

Where are the results?

Every output is a MOV beside its source, named CMPRS-[name]. A number is added if the name already exists. Originals and previous results are never overwritten. Show results opens the saved files in Finder.

Why was no extra copy saved?

If the result is not smaller, CMPRS does not keep an extra copy. This is common with already compressed sources. Compression is lossy and results depend on the source. Review important results before replacing any copies.

Which files are supported?

Input support depends on macOS media frameworks. HDR, Dolby Vision, transparency, unsupported tracks or formats and complex edited sources may be refused with an explanation. CMPRS keeps the original frame size, orientation and frame timing for supported files. The app runs on macOS 13 or later, with builds for Intel and Apple Silicon.

What if progress stops?

Check the status and any error. Use Copy diagnostics and email your CMPRS and macOS versions, Mac model, source format and error to uralsocket@gmail.com. Review diagnostics before sending: they can contain filenames and paths. They are never sent automatically. Usually the source video is not needed for initial troubleshooting. You can cancel a batch.

Does this also describe Ironclad 1.x?

No. Legacy 1.x uses the Ironclad software engine and an older interface and Finder action. The two native codecs and ASCII-eye design belong to CMPRS 2. See the release page for each version. The new 2.0 beta is being prepared for public download.
