How do I install CMPRS?

Download the DMG, open Install CMPRS, and click Install. The app goes into ~/Applications and one Finder service is registered. Requires Apple Silicon and macOS 13 or later.

Where is the Finder action?

Select video files and open the context menu. Look for CMPRS — Compress video; macOS may place it under Services. If hidden, enable it in System Settings → Keyboard → Keyboard Shortcuts → Services → Files and Folders.

Where are the results?

A separate CMPRS-[name].mov appears beside the original only if smaller. Existing files are never overwritten. macOS may ask you to allow that exact source folder.

How is the language selected?

The app follows its macOS application language: English or Russian, with English as the fallback. Relaunch after changing that language in macOS. The website has its own EN/RU switch and opens in English for new visitors.

Why was a file skipped?

A result is discarded if it is not smaller. Unsupported HDR/Dolby Vision, transparency, pixel formats or tracks are left unchanged. Compatible H.264 uses 8-bit 4:2:0; reducing 10/12-bit depth requires confirmation for the batch.

What if processing stops?

Use Cancel. CMPRS stops the encoder and removes its temporary output. The queue shows a short error for files that fail. Email the app and macOS versions, Mac model, input format and visible error to uralsocket@gmail.com. CMPRS does not save log files or diagnostic reports.

How do I remove the Finder action?

Disable CMPRS — Compress video under Keyboard → Keyboard Shortcuts → Services → Files and Folders. Old Automator workflows can be removed from ~/Library/Services. Removing the app does not delete your videos.
