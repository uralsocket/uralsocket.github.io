Your videos.
On your computer.

Updated October 27, 2026 · CMPRS 2.0 / 2.0.1

Local processing

CMPRS is developed by Gleb Karavaev. Video and audio are processed locally on your computer. The app does not upload your files, require an account, include advertising or collect analytics.

No processing logs or history

CMPRS 2.0 does not write log files, batch reports or processing history. Encoder diagnostics are discarded. Queue details and short errors exist only in the current app session. macOS, Windows or their web runtimes may separately create security or crash information according to your system settings. Older CMPRS releases may have created local logs; updating does not automatically remove old app data.

Files and folder access

Folder access is used only to read selected sources and write temporary compression output and final MOV files beside them. On macOS, source-folder grants are held for the app session without storing folder bookmarks. Windows uses ordinary permissions for the selected files and folders. Temporary processing output is removed on normal completion or cancellation. Original and earlier output files are not overwritten. You control and delete your videos through Finder or File Explorer.

Interface and language

The app uses local interface resources. macOS uses an ephemeral WebKit data store; Windows uses a temporary InPrivate WebView2 profile, with cleanup on normal exit. External navigation and network requests from the local interface are blocked. The app follows the system/application language and stores no separate language preference. The Mac FFmpeg build has networking disabled; the Windows app restricts FFmpeg input protocols to local files and pipes. The Windows installer may contact Microsoft to install WebView2 if missing. Runtime updates and operating-system diagnostics are managed by Apple, Microsoft and your system settings.

Support email

If you email uralsocket@gmail.com, Gleb Karavaev receives your sender address, message and attachments you choose to send, to respond and troubleshoot. Email is delivered through Gmail. Contact the same address to request deletion of support correspondence. Videos are not required for an initial support request.

This website

These pages are hosted on GitHub Pages. The host may process ordinary request information such as IP addresses and request times under its privacy policy. These CMPRS pages include no analytics, advertising or video-upload forms. The EN/RU website preference is stored locally in your browser; new visitors see English. This setting is separate from the app language.
