Политика конфиденциальности

FinHelper разработан Gleb Karavaev. Эта политика описывает обработку информации приложениями FinHelper для iOS, iPadOS и macOS.

Локальные финансовые данные

Счета, балансы, транзакции, категории, лимиты, ожидаемые поступления, имена клиентов, комментарии, настройки и сформированные отчёты хранятся локально на устройстве пользователя. Разработчик не использует сервер FinHelper или систему учётных записей, получающую эти данные.

Если пользователь включает синхронизацию через папку, FinHelper сохраняет файл данных только в папке, выбранной пользователем через системный интерфейс, включая iCloud Drive. FinHelper не добавляет к этому файлу собственное шифрование. Управление доступом, шифрование при хранении и передаче, сроки хранения и удаление обеспечиваются устройством и выбранным поставщиком хранилища.

Курсы валют и криптовалют

FinHelper запрашивает публичные котировки у Frankfurter, Binance и, при необходимости, Coinbase. Запрос содержит обозначения валют или активов и обычные сетевые метаданные, например IP-адрес. Счета, балансы, транзакции, категории, комментарии, клиенты и резервные копии этим сервисам не передаются.

Необязательный умный анализ Gemini

Умный анализ запускается только после того, как пользователь самостоятельно укажет личный Gemini API-ключ и нажмёт кнопку анализа. FinHelper не обращается к Gemini в фоне и не повторяет неудачные запросы автоматически.

Для анализа Google Gemini получает подготовленное финансовое досье выбранного периода. Оно может включать балансы неархивных счетов, агрегаты и отдельные сведения о транзакциях, категории, лимиты, ожидаемые поступления, имена клиентов, комментарии, локально рассчитанные показатели и ограниченную по размеру часть предыдущего отчёта. Архивные счета, файл синхронизации и посторонние данные устройства не передаются. API-ключ хранится в Keychain и не включается в резервные копии или синхронизацию. Условия обработки Google зависят от тарифа Gemini API пользователя; разработчик FinHelper не получает досье или ответ модели.

Отслеживание, реклама и биометрия

В FinHelper нет рекламы, сторонних аналитических SDK, межприложенческого отслеживания и продажи персональных данных. Face ID обрабатывается системными средствами Apple; приложение получает только результат проверки и не получает биометрические шаблоны.

Резервные копии и удаление

Пользователь может экспортировать резервную копию и самостоятельно выбрать место сохранения, удалить операции или сбросить данные приложения. Экспортированные и синхронизированные файлы остаются под контролем пользователя и удаляются отдельно в месте их хранения.

Дети, изменения и контакты

FinHelper является общим инструментом учёта финансов и не предназначен специально для детей. Существенные изменения политики отражаются обновлением текста и даты вступления в силу.

Privacy Policy

FinHelper is developed by Gleb Karavaev. This policy explains how the FinHelper applications for iOS, iPadOS, and macOS process information.

Local financial data

Accounts, balances, transactions, categories, limits, expected payments, client aliases, comments, settings, and generated reports are stored locally on the user's device. The developer does not operate a FinHelper account system or server that receives this data.

If the user enables folder synchronization, FinHelper writes a data file only to a folder explicitly selected through the system interface, including iCloud Drive. FinHelper does not add application-level encryption to this file. Access control, encryption at rest and in transit, retention, and deletion are provided by the device and the selected storage provider.

Currency and crypto rates

FinHelper requests public market data from Frankfurter, Binance, and Coinbase as a fallback. Requests contain currency or asset symbols and ordinary network metadata such as an IP address. Accounts, balances, transactions, categories, comments, clients, and backups are not sent to these services.

Optional Gemini Smart Analysis

Smart Analysis runs only after the user provides a personal Gemini API key and presses the analysis button. FinHelper does not contact Gemini in the background or automatically retry failed requests.

For an analysis, Google Gemini receives a purpose-built financial dossier for the selected period. It may include balances from non-archived accounts, transaction aggregates and selected transaction details, categories, limits, expected payments, client aliases, comments, locally calculated metrics, and a size-limited part of the previous report. Archived accounts, the synchronization file, and unrelated device data are excluded. The API key is stored in Keychain and is not included in backups or synchronization. Google's processing terms depend on the user's Gemini API tier; the FinHelper developer does not receive the dossier or response.

Tracking, advertising, and biometrics

FinHelper contains no advertising, third-party analytics SDK, cross-app tracking, or sale of personal data. Face ID is processed by Apple system frameworks; FinHelper receives only the success or failure result and never receives biometric templates.

Backups and deletion

Users can export a backup and choose its destination, delete operations, or reset application data. Previously exported or synchronized files remain under the user's control and must be deleted separately at their storage location.

Children, changes, and contact

FinHelper is a general personal-finance tool and is not directed to children. Material changes will be reflected by updating this policy and its effective date.
